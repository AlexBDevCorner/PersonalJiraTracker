# features

Feature modules wired into the router (REQ-UI-012):

- `timesheet/` — weekly grid, daily/weekly totals, cell popover
- `board/` — assigned tickets grouped by Jira workflow status, immediate transitions and automatic refresh
- `favorites/` — pinned issues and groups
- `settings/` — Jira credentials and app settings

Each feature owns its own components, hooks, and state.
